# 🧮 Age Calculator

A simple and interactive web application to calculate your exact age in years, months, and days. Built with HTML, CSS, and JavaScript — perfect for learning date manipulation and user interaction.

## 🔍 Features

- 🎯 Calculates age accurately based on input date
- 📆 Shows years, months, and days
- 🧠 JavaScript date logic
- 💡 Minimal, responsive UI design


## 🚀 Live Demo

🌐 [View it on Vercel](https://age-calculator-seven-silk-97.vercel.app/)

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
